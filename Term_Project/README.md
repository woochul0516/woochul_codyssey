## 1. 기술 기획
#### 1. 비전 및 센서 융합 인식 모듈 (Vision & Sensor Fusion Engine)
- 객체 탐지 (Object Detection):
    - 모델: YOLOv10 / RT-DETR 기반의 경량화 Real-time Detection 모델
    - 탐지 대상: 사람, 차량, 작업 도구, 동물, 울타리 파손, 전력 설비 아크(Sparks/화재)
    - 성능 목표: Edge NPU 상에서 30 FPS 이상 처리, FP16/INT8 양자화 적용
- 센서 융합 (RGB + Thermal Fusion):
    - 기술: RGB 카메라와 열화상(Thermal) 센서 데이터의 Early/Late Fusion
    - 역할: 야간, 안개, 미세먼지 등 악천후 상황에서 열 스펙트럼 데이터를 융합하여 야간 인적 탐지율 98% 이상 확보

#### 2. 지능형 자율비행 및 위치 추정 모듈 (Spatial AI & SLAM Engine)
- 3D 공간 인지 및 위치 추정 (Visual-LiDAR SLAM):
    - 기술: Solid-state LiDAR + Stereo Camera 융합 기반 FAST-LIO / ORB-SLAM3
    - 역할: 고압선 주변 등 GPS 신호가 교란되거나 음영인 구역에서도 센서 데이터만으로 3D 점군(Point Cloud) 지도 생성 및 자체 위치 추정
- 동적 장애물 회피 (Dynamic Obstacle Avoidance):
    - 기술: 3D Occupancy Grid Mapping + DWA(Dynamic Window Approach) & 강화학습 기반 경로 재계산
    - 역할: 바람에 흔들리는 고압선, 순간 비행 조류, 기상 변화 발생 시 50ms 이내 최적 비행 경로 재설정
- 고압선 정밀 도킹 AI (Precision Docking):
    - 기술: ArUco 마커 인지 + IR 비콘 추적 + 초음파 거리 센서 PID 제어
    - 역할: 오차 범위 ±2cm 이내의 고압선 유도 충전 거치대 자동 결합

#### 3. 상황 판단 및 위협 추론 모듈 (Context Reasoning & Anomaly Engine)
| 기능 구분 | 적용 기술 / 알고리즘 | 세부 동작 및 역할 |
| :--- | :--- | :--- |
| **행동 패턴 분석** | Pose Estimation (RTMPose / MediaPipe) + ST-GCN | • 인물의 월담, 배회, 쓰러짐, 침입 시도 동작을 관절(Skeleton) 데이터 기반 실시간 추적 |
| **정상/이상 작업 구별** | Zero-Shot VLM (Moondream / Florence-2) + Rule-Engine | • 안전모/작업복 착용 여부 및 작업 허가 시간대 검증<br>• 미인가자의 펜스 접근 시 침입 위험도(Level 1~3) 자동 산정 |
| **오경보(False Alarm) 필터링** | Dynamic Thresholding & Temporal Tracking | • 바람에 흔들리는 수목, 소형 동물 이동 등 무해한 위협 요소 95% 이상 자체 컷오프 |

#### 4. 에지-클라우드 AI 파이프라인 및 MLOps (Data & Deployment)
- Edge AI (드론 온디바이스 AI):
    - 하드웨어: NVIDIA Jetson Orin Nano / NPU 탑재 싱글보드
    - 최적화: TensorRT 컴파일, INT8 Quantization 적용으로 소모 전력 15W 이내 유지
    - 역할: 실시간 객체 탐지, 장애물 회피, 1차 위협 판단을 온디바이스에서 즉시 처리 (네트워크 전송 지연 최소화)
- Cloud AI (관제 서버 & MLOps):
    - 역할: 복잡한 VLM 기반 맥락 추론, 전사적 경비 로그 관리, 모델 재학습
    - Active Learning & Synthetic Data: 현장에서 수집된 Edge 데이터 중 추론 불확실성(Uncertainty)이 높은 샘플을 클라우드로 자동 전송하여 주간 단위 모델 자동 업데이트 진행 (Isaac Sim 활용 가상 시뮬레이션 데이터 융합)

## 2. 핵심 개념
#### 1. 비전 및 센서 융합 인식 모듈 (드론의 '눈')
- 객체 탐지: 카메라 화면 속에 보이는 대상이 사람인지, 차인지, 불꽃(아크)인지 네모 상자를 치며 실시간으로 이름을 붙여주는 기술입니다. 드론이 날아가며 1초에 30장 이상의 화면을 끊김 없이 분석합니다.
- 센서 융합 (RGB + 열화상): 사람 눈에 보이는 일반 컬러 영상과 체온을 감지하는 열화상 영상 두 개를 하나로 합치는 기술입니다. 캄캄한 밤이나 안개가 자욱한 날에도 침입자를 놓치지 않고 잡아냅니다.

#### 2. 지능형 자율비행 및 위치 추정 모듈 (드론의 '운전 실력')
- 3D 공간 인지 (SLAM): GPS 신호가 안 터지는 전력망 근처에서도 드론이 레이저(LiDAR)와 카메라로 주변 3D 지도를 스스로 그리며 자기 위치를 찾아가는 '자율 내비게이션'입니다.
- 동적 장애물 회피: 갑자기 새가 날아들거나 전선이 바람에 흔들릴 때, 0.05초(50ms) 만에 부딪히지 않게 다른 길로 싹 돌아가는 순발력입니다.
- 고압선 정밀 도킹: 정밀 센서와 눈지표(ArUco 마커)를 이용해 드론이 고압선 충전 거치대에 손가락 한 마디 오차(±2cm) 없이 딱 가서 붙는 기술입니다.

#### 3. 상황 판단 및 위협 추론 모듈 (드론의 '두뇌')
- 행동 패턴 분석: 사람을 그냥 '사람'으로 보는 게 아니라, 관절 움직임을 추적해 "저 사람은 지금 담을 넘고 있구나", "기절해 있구나"를 판별합니다.
- 정상/이상 작업 구별: AI가 "안전모를 썼나?", "지금 작업 허가 시간인가?"를 따져 정식 작업자인지 무단 침입자인지 위험 등급(1~3단계)을 스스로 정합니다.
- 오경보 필터링: 바람에 나뭇가지가 흔들리거나 길고양이가 지나가는 것 때문에 가짜 경보가 울리지 않도록 95% 이상 걸러내는 똑똑한 필터입니다.

#### 4. 에지-클라우드 AI 파이프라인 (드론과 중앙 관제실의 '분업')
- Edge AI (드론 탑재 AI): 드론에 작고 효율적인 소형 AI 컴퓨터(NVIDIA Jetson)를 직접 달았습니다. 인터넷이 끊겨도 순발력이 필요한 장애물 회피나 사람 찾기를 현장에서 즉시 처리하며, 전력도 적게 먹습니다.
- Cloud AI (중앙 관제 서버): 현장 드론이 판단하기 애매했던 복잡한 영상만 서버로 보내 정밀 분석합니다. 드론이 헷갈려했던 데이터는 가상 시뮬레이션(Isaac Sim)으로 만들어 매주 AI를 더 똑똑하게 재학습시킵니다.

## 3. 하드웨어
#### 1. 메인 AI 컴퓨터 (Edge AI Board)
- NVIDIA Jetson Orin Nano / Orin NX
    - 역할: 드론에 탑승하는 메인 AI 두뇌로, YOLO 객체 탐지와 자율비행 SLAM 연산을 수행.
    - 특징: 소형 스마트폰 크기 모듈로 최대 40~100 TOPS의 AI 연산 처리 성능을 내며, 소비 전력이 7~25W(Orin NX의 경우 확장/슈퍼 모드 사용시 최대 40W) 수준으로 배터리 소모를 극도로 줄여줌.
#### 2. 3D 라이다 센서 (3D LiDAR)
- Livox Mid-360
    - 역할: 레이저를 쏘아 주변 3차원 공간 지도를 그리고, GPS가 안 터지는 전력망 근처에서 내비게이션 역할을 담당.
    - 특징: 무게가 265g으로 가벼워 드론 장착에 적합하며, 수평 360도, 수직 약 59도의 시야각을 감지해 전선이나 장애물 충돌을 방지.
#### 3. 열화상 카메라 모듈 (Thermal Sensor)
- Teledyne FLIR Boson 640
    - 역할: 야간 탐지 및 전력 설비의 이상 과열/아크(불꽃) 현상 감지.
    - 특징: 초소형(렌즈 미포함 시 약 7.5g) 및 초저전력(0.6W) 모듈로, 640x512 고해상도 열 스펙트럼 데이터를 실시간 추출.
#### 4. 비행 제어 컴퓨터 (Flight Controller, FC)
- Holybro Pixhawk 6X / 6C
    - 역할: Jetson AI 컴퓨터가 명령을 내리면 모터와 날개를 직접 제어해 실제 비행을 수행.
    - 특징: 산업용 드론 표준 오픈소스(PX4/ArduPilot) 기반이며, 3개의 2중 IMU(센서)가 탑재되어 고압선 강한 전자기장 속에서도 안정적 비행을 유지.
#### 5. 고압선 유도 충전 모듈 (In-Flight Inductive Charger)
- C-Core 변류기(CT, Current Transformer) 유도 충전 클램프
    - 역할: 드론이 고압선 거치대에 착륙했을 때, 선로 주변의 전자기장을 흡수해 배터리를 무선 충전.
    - 특징: 별도의 전원 케이블 연결 없이 전력선 자체의 전력 일부를 유도 전류로 변환하여 드론을 24시간 연속 운용할 수 있게 만듦.

## 4. 예상 질문 및 답변
#### Q1. 고압선 주변은 굵은 전선 때문에 GPS가 잘 안 터지는데, 드론이 길을 잃거나 추락하지 않나요?
- A: 그래서 GPS에 의존하지 않는 Visual-LiDAR SLAM 기술을 적용했습니다. 드론이 자체 센서로 주변 구조물의 3D 입체 지도를 실시간으로 직접 그리며 내비게이션을 수행하므로, GPS가 완전히 먹통이 되는 환경에서도 흔들림 없이 안정적으로 비행합니다.

#### Q2. 바람에 나뭇가지가 흔들리거나 길고양이가 지나갈 때마다 경보가 울리면 관제 인력이 피로해지지 않을까요?
- A: 단순히 형체만 보는 것이 아니라, 사람의 관절 움직임(Pose Estimation)과 시간대별 행동 맥락을 함께 분석합니다. 나뭇가지의 흔들림이나 소형 동물의 움직임은 AI가 '무해한 자극'으로 판단해 95% 이상 자동으로 걸러내므로 오경보 스트레스가 거의 없습니다.

#### Q3. 드론이라는 작은 기체에 AI 컴퓨터를 넣으면 배터리가 너무 금방 닳지 않나요?
- A: AI 모델을 가볍게 다듬는 'INT8 양자화'와 'TensorRT 최적화' 기법을 적용해 AI 연산에 들어가는 전력을 15W 이하(스마트폰 충전기 수준)로 극도로 줄였습니다. 여기에 본 시스템의 핵심인 고압선 유도 충전 방식을 결합해 배터리 걱정 없이 24시간 연속 운용이 가능합니다.

#### Q4. AI가 한 번도 본 적 없는 새로운 유형의 침입이나 이상 행동이 발생하면 어떻게 대처하나요?
- A: 드론이 현장에서 추론 불확실성(Uncertainty)이 높다고 느낀 생소한 장면은 자동으로 클라우드 서버에 저장됩니다. 이를 가상 시뮬레이터(NVIDIA Isaac Sim)로 다각도 합성 데이터로 재창조한 뒤, 매주 주간 단위로 AI를 재학습시켜 드론에 최신 모델을 무선(OTA) 업데이트합니다.
